# Lantern of the Willow

`Lantern of the Willow` is URPG's bounded governed vertical-slice scenario. A
first playthrough must fit within fifteen minutes: begin in Willow Village,
cross to Moonwell Shrine, and return the lantern to the village elder.

## Creator workflow

1. Create or open a JRPG project through the startup shell. The Classic JRPG
   wizard can seed the two-map `Lantern of the Willow` draft; that seed remains
   explicitly incomplete until its listed native contextual routes round-trip.
2. Attach only the acceptance-manifest entries through Assets.
3. Use Map to author both maps, their events, the shrine gate prop state, and
   the two NPCs.
4. Bind abilities, vendor stock, encounter, dialogue, quest, and save point
   through their contextual routes.
5. Run the vertical-slice gate before packaging. It rejects raw/external
   paths, local indexes, recovery snapshots, and playtest overlays.

## Asset contract

The example references only existing release-governed proof-asset lanes from
`content/fixtures/project_governance_fixture.json`. It does not import,
attach, or package raw external sources. Exact promoted payload hydration is
still required before package qualification.

## Completion boundary

This artifact defines the integration contract. It is not evidence that all
contextual editor routes, runtime steps, or package evidence are complete;
those remain explicit blockers until generated by native workflows.
