# RPG Maker MZ Project Corpus Fixtures

This directory holds legal corpus descriptors for high-end RPG Maker MZ compatibility evidence.

Descriptors are allowed here. Copyrighted RPG Maker editor data, RTP payloads, paid sample projects, and third-party plugin source are not allowed unless a release owner records an explicit private-owner fixture policy outside Git.

Allowed sources:

- `repo_owned`: synthetic URPG-authored descriptor data only.
- `permissive_sample`: sample content with a tracked permissive license and attribution.
- `owner_provided_private`: descriptor metadata for local/private validation; no copyrighted payload may be committed.

Every descriptor must set `fixtureScope.copyrightedRpgMakerPayloadsIncluded` to `false`.
